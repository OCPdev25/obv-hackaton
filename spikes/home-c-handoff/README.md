## The lens

The home **leads with the takeover brief**: what the on-duty caregiver needs to take over care
right now. Capture (voice-first, typed fallback) and the event feed serve the brief. The teaching
point S1 forces: the nap → night-waking **correction changes the plan** for the next caregiver —
a feed-first home buries that; a handoff-first home puts it above the fold with lineage attached.
